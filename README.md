# KettlebellHelper

Статический сайт с программой ежедневных тренировок с гирей на всё тело. Тренировка идёт по шагам: одно упражнение на экране, анимация техники, число повторений или таймер, переход вперёд и назад. Без авторизации и хранения данных, хостится на GitHub Pages.

## Стек

SvelteKit 2 (Svelte 5) + TypeScript, adapter-static с пререндером всех страниц, Tailwind 4, Skeleton 3.

## Локальный запуск

```cmd
npm install
npm run dev
```

Проверки: `npm run check` и `npm test`.

## Деплой на GitHub Pages

1. В Settings > Pages репозитория выбрать Source = GitHub Actions.
2. Запушить `main`, пайплайн соберёт и опубликует сайт по адресу `https://<user>.github.io/<репозиторий>/`. Base path берётся из имени репозитория.

## Где что лежит

- `src/lib/exercises.ts`: упражнения, подсказки по технике и позы для анимации.
- `src/lib/programs.ts`: программы по уровням и разворачивание программы в список шагов.
- `src/lib/Figure.svelte`: анимированная фигурка (SVG + SMIL), локти и колени досчитываются по положению кистей и стоп.
- `src/lib/Timer.svelte`: таймер для упражнений на время, по окончании звук и вибрация.

## Как добавить программу

Добавить объект в `programs` в `src/lib/programs.ts`: разминка, круг упражнений с повторениями (`reps`) или временем (`seconds`), число кругов и отдых между ними. Упражнение на каждую руку помечается `perSide: true`. Страница программы появится сама.

Новое упражнение описывается в `src/lib/exercises.ts`: вид сбоку лицом вправо, пол на `y = 180`, ключевые позы задаются положением таза, наклоном корпуса, кистями и стопами.
